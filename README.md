# External-Memory

**External-Memory** — это десктопное приложение для разработчиков, которое помогает не терять контекст проектов. Оно хранит задачи, архитектурные решения, заметки и историю рабочих сессий в одном месте, чтобы после перерыва вы могли вернуться в работу за пару минут, а не вспоминать всё заново.

## 📌 Статус

В активной разработке. Проект открыт для предложений и идей. Open-source.

## ✨ Основные возможности

- **Task Board** — Канбан-доска с мультивыделением, фильтрацией и мягким удалением (soft delete).
- **Context** — Снимок состояния проекта (что в работе, что сделано, планы, открытые вопросы).
- **Sessions** — Трекер рабочих сессий. Позволяет зафиксировать, на что был потрачен фокус, что получилось, а что нет.
- **Architecture** — Разделение логики и UI (паттерн MVC) для легкой масштабируемости.

## 🛠 Технологический стек

- **Язык:** Java 21
- **UI:** JavaFX (кастомные стили через CSS)
- **База данных:** PostgreSQL
- **ORM:** Hibernate / Jakarta Persistence
- **Сборка:** Gradle
- **Инфраструктура:** Docker (для быстрого развёртывания БД)

## 🏗 Архитектура

Проект построен с разделением ответственности:
- **Views (UI)** — только отрисовка интерфейса.
- **Controllers** — обработка событий, логика приложения (`TaskController`, `SessionController`).
- **DAO** — слой доступа к данным (Generic Repository pattern).
- **Entities** — JPA-сущности.

## 🚀 Как запустить

### Требования
- Java 21 (JDK)
- Docker и Docker Compose

### Шаги установки

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Ozi-s/external-memory.git
   cd external-memory
   ```
2.  **Поднимите базу данных:**
    ```bash
    docker-compose up -d
    ```
    База данных PostgreSQL запустится на порту 5434.
3.  **Настройте конфигурацию:**
    Скопируйте hibernate.cfg.xml.example в src/main/resources/hibernate.cfg.xml и укажите ваши данные (по умолчанию: логин postgres, пароль postgres, база externalMemory).
4. **Запустите приложение:**
    ```bash
    ./gradlew run
    ```
